what the states mean

    armed — the sweep is on and a coordinator is recorded, so a Send is woken and read.
    no coordinator — the sweep has nobody to wake; start one above.
    unread send — notes were sent and the wake has not consumed them yet.
    no sweep — the daemon was started with --sweep 0.
    stopped — a STOP flag is set; the loop is over until someone clears it.
    

      Nothing has to be parked any more: the daemon notices work itself. A topic with notes and
      no coordinator is the state to fix. Chrome/CSS changes only reach an open canvas after a
      browser reload.
